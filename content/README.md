These files contain declarative scene, geometry, material, transform and descriptive data. They contain no executable model-building functions. The software loads them using the documented Three.js object format and generic application adapters; the loaders, rendering, editing and scheduling behavior are AGPL-3.0-only software.

The separation allows the software to be used with replacement content. Preserve the required schemas and stable object references when replacing a pack, or migrate saved scenarios that refer to its object IDs. The model remains illustrative rather than a surveyed hospital building. [Source provenance](../docs/FLOOR-SOURCES.md) explains those limits.

When sharing the original content or adaptations, provide attribution, identify changes and follow the license's noncommercial and share-alike conditions.
